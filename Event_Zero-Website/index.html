SECTION 01The Verdict: a proof-backed YES or NO on any file you download

Drop in a cracked game, a keygen, an installer, an archive, or a whole release folder. The Verdict takes it apart piece by piece and accounts for every byte as genuine program or explained crack. One headline comes back. Not a score. Not a probability.

Headline one

YES: MALWARE FOUND, PROVEN

A behaviour chain was demonstrated: theft, a miner mining for someone else, persistence plus a remote host, antivirus tampering, or the scope test, which is the first behaviour a file does not need for its claimed job.

Headline two

YES: MALWARE FOUND, UNACCOUNTED

Something could not be explained: an unexplained code region, an archive layer that would not open, a virtualized section. The accounting fails closed. Silence never becomes a pass.

Headline three

NO: NO MALWARE, ACCOUNTED

Issued only when every byte is accounted for as genuine or explained crack, against a signature-valid original or a fully classified diff. The crack itself is never counted as malware: a patched licence check, a key generator, and KMS emulation sit in the accounting, not the proof.

SECTION 05Three rings: core, adapters, services

Event Zero does not replace the tools in the outer rings. It fuses them into one evidence file, and credits each by name.

Ring 1: built in

Parsers, decoders, unpacking, firmware, rootkit indicators, evasion, verdict accounting, ledgers, ELI5, defences (YARA, Sigma style summary, IOC exports), and its own tools: ez-carver, ez-shellcode, ez-capgen, ez-diff.

Ring 2: adapters

Ghidra headless, capa, FLOSS, radare2, binwalk, unblob, Detect It Easy, YARA, binutils, Speakeasy, Unicorn, Volatility 3, jadx, oletools, tshark. Detected automatically, used when installed, absent gracefully.

Ring 3: services

VirusTotal, Hybrid Analysis, MalwareBazaar, ThreatFox, URLhaus, urlscan.io, OTX, MetaDefender, filescan.io, tria.ge. Hash first, keys from the environment only. Gemini sits outside the rings as the optional narration layer, behind the evidence gate.

SECTION 06Safety and honest limits

Samples are never executed on the host. Reports are built by reading bytes. Emulation services no syscalls. Detonation belongs in your own isolated CAPE sandbox.

Full decompilation of packed or virtualized code is not possible, for any tool. Event Zero censuses virtualized regions, traces what crosses into the real world, and marks the rest UNACCOUNTED rather than guessing.

A NO from The Verdict is an accounting claim, stated exactly: every byte accounted for as genuine or explained crack, no behaviour beyond genuine plus explained crack observed, manifest linked. Environment-keyed and server-gated payloads stay on the disclosed open list.

Zero-day is a disclosure status, not something a binary can certify. Exploit reports state the bug class and the primitive, and print disclosure status: unknown.
